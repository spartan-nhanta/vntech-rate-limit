Hands on

Open it in four tabs and get throttled

A live page, not a screenshot: a simulated GET /api/next-phone-number guarded by a real token bucket. Open the link below in three or four tabs and mash the button in each — they all share one bucket through localStorage, the same way replicas behind a load balancer share one Redis-backed limiter.

  • Shared bucket — every tab draws from the same 5 tokens, refilling at 1/s, no matter how many tabs are open.
  • Per-tab bucket — flip the toggle and each tab gets its own bucket, reproducing the multi-pod counter bug from §3.1.

The reference project's own demo goes further: an admin page that switches the live algorithm and its parameters without a restart, a per-user state visualizer over SSE, and a scripted "boundary spike" run that times a burst to land exactly across a Fixed Window reset.
